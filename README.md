# HH Goa 2026 - Builder ID Card Generator

A comprehensive Builder ID Card Generator for the 2026 Housing Handover Goa conference.

## Features

- **Builder ID Card Generation**: Create professional ID cards with high-quality design.
- **Photo Upload**: Upload participant photos for the ID cards.
- **Customizable Design**: Includes specific design elements for the HH Goa 2026 event.
- **Simple User Interface**: Easy-to-use interface for generating cards quickly.

## Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Deploy to Vercel**:
   ```bash
   vercel --prod
   ```
